# 🏫 ระบบเว็บไซต์สำนักงานโรงเรียนบ้านหนองหว้า (ระบบประมวลผล PHP & MySQL)

ยินดีต้อนรับเข้าสู่อภิสิทธิ์โครงสร้างรหัสพัฒนาคุณภาพสูงสำหรับ **โรงเรียนบ้านหนองหว้า** (อัตลักษณ์ ชมพู-ขาว) พัฒนาขึ้นในรูปแบบภาษา **PHP 8+** และการเชื่อมต่อความปลอดภัยระดับสูงผ่าน **MySQL PDO** 

ระบบนี้เป็นแบบ **Server-Ready** ที่ผ่านการล้างโค้ด Node.js / React / TypeScript และไฟล์ระบบส่วนเกินทั้งหมดออกแล้ว เหลือคงไว้เฉพาะสคริปต์ภาษา PHP แท้ 100% ทำให้เบาหวิวและปลอดภัยสูงสุดในการโอนย้ายข้อมูลผ่าน GitHub หรืออัปโหลดสดขึ้นบน Web Server (เช่น DirectAdmin, cPanel / Apache / Nginx Co-location Hosting)

## 📂 โครงสร้างไพล์ภาษา PHP ทั้งหมดที่พร้อมใช้งานในระบบ
ไฟล์ PHP หลักทั้งหมดถูกสร้างเสร็จเรียบร้อยและปรากฏอยู่ในรากของ File Explorer ของคุณ โดยมีหน้าที่ของแต่ละส่วนดังนี้:

1. **`db_connect.php` (แทนที่ config.php แบบเดิมเพื่อความปลอดภัยสูงสุด)** 
   - 📡 **การเชื่อมต่อและรักษาความลับ**: ทำหน้าที่เชื่อมต่อฐานข้อมูล PDO ป้อนรหัสภาษา UTF-8 เต็มระบบ พร้อมฟังค์ชัน `cleanInput` (ป้องกัน XSS) และ `thaiDate` (จัดรูปแบบวันที่ไทย)
   - 🛡️ **ไม่มีปัญหาการทับไฟล์**: เปลี่ยนชื่อช่วยป้องกันไม่ให้เวลาที่ท่านทำการเชื่อม Git Push ขึ้นไปทับการเชื่อมต่อฐานข้อมูลเดิมของเซิร์ฟเวอร์หลักของโรงเรียนโดยบังเอิญ! หากท่านต้องการเก็บค่าเดิมเอาไว้ สามารถเลือกที่จะไม่อัปโหลดไฟล์นี้ร่วมกับสคริปต์อื่นได้

2. **`db_migrate.php` (ระบบอัปเดตและโครงสร้างฐานข้อมูลแบบแยกส่วน)**
   - 🛠️ **รันติดตั้งเฉพาะตัวกรณีติดตั้งครั้งแรก**: รวมศูนย์คำสั่งสร้างตารางหลัก (`settings`, `users`, `news`, `teachers`, `students`, `downloads`, `banners`) คอลัมน์ที่ขาดหายชำรุด และข้อมูลนโยบายโรงเรียน ข่าวสาร สถิติ บุคลากรจำลองตั้งต้น
   - 📂 **สะดวกในการเคลื่อนย้าย**: ด้วยโครงสร้างที่แยกเป็นอิสระนี้ ทำให้เวลาที่หน้าเว็บโหลดปกติจะไม่ต้องรัน SQL ตรวจสอบตารางในทุกฟังก์ชัน สามารถเข้าเบราว์เซอร์แล้วรันเช่น `http://yourdomain.com/db_migrate.php` เพียงเพื่ออัปเดตหรือติดตั้งครั้งเดียว

3. **`index.php`**
   - 🌸 **หน้าพอร์ทัลหลักสีชมพู-ขาว**: หน้าตึกพอร์ทัลต้อนรับผู้ปกครองและประชาชน พัฒนาแบบเบาหวิวด้วย Tailwind CSS Play CDN และไอคอนโมเดิร์น Lucide Icons ไม่ต้องทำ Node compilation 
   - 📊 **สถิติและข่าวสาร**: ดึงแบนเนอร์ประชาสัมพันธ์, ตัวกรองฝ่ายงานกลุ่มสาระครู, จำแนกสัดส่วนนักเรียนชายหญิง และนำเสนอยอดผู้เข้าชมทั้งหมดที่ป้อนอัปเดตลงเซสชัน MySQL

4. **`login.php`**
   - 🔐 **หน้าเข้าสู่ระบบความปลอดภัยสูง**: ป้องกันการแอบมองหน้าจอ ฟอร์มสวยงามกรองสีชมพูขาว และเข้ารหัสความลับแอดมินด้วยกรรมวิธี Bcrypt (`password_verify`) ป้องกันฟิชชิงและการขโมยสิทธิข้อมูล

5. **`admin.php`**
   - 🏢 **ระบบแอดมินบอร์ด (หลังบ้าน)**: ตัวเลือกการเพิ่มกระดานข่าว ขอบเขตสำคัญสำหรับเพิ่มข่าวด่วนปักหมุดข่าววิกฤติ, เพิ่มไฟล์แผนงานจัดซื้อจัดจ้างประดับคลัง และบันทึกบุคลากรวิทยฐานะเข้าทำเนียบลำดับเรียงรายคลาส

6. **`download_file.php`**
   - 📥 **บันทึกกิจกรรมดาวน์โหลด**: ตรวจจับความเคลื่อนไหวการเข้าสิทธิไฟล์เอกสารราชการ เมื่อมีผู้ใช้งานคลิกดาวน์โหลด ระบบจะทำการบันทึกบวกหนึ่งยอดเข้าชมและสแกนดาวน์โหลดลง MySQL และนำทางดาวน์โหลดไปที่อยู่ไฟล์ปลายทางอย่างลื่นไหล

## 🛠️ วิธีการเชื่อมต่อและอัปโหลดไปยัง Web Server โรงเรียน
ตามวิธีที่ท่านแจ้งว่าใช้งานร่วมกับการเชื่อมต่อ GitHub อัตโนมัติ:

1. **ลำดับทางเข้าใช้งาน (Directory Ingress)**:
   - โดยปกติ เว็บเซิร์ฟเวอร์แบบส่วนตัว (Apache/NGINX) บน Linux Web Hosting จะจัดให้ **`index.php`** ทำงานก่อน `index.html` เสมอ
   - และที่สำคัญ เราได้ทำความสะอาด (Clean-up) ลบโครงสร้าง React หน้าขาวดั้งเดิมและหน้า index.html ออกไปแล้ว ทำให้มีเพียง `index.php` เป็นแกนรับหน้าแรก 100% หมดปัญหาข้อผิดพลาด 404 (File not found) แน่นอน

2. **การตั้งค่าชื่อเชื่อม MySQL บัญชีโรงเรียนจริง**:
   - ท่านสามารถปรับแก้ข้อมูลตัวแปรการเชื่อมฐานข้อมูลอย่างปลอดภัยได้ที่ไฟล์ **`db_connect.php`** (และ **`db_migrate.php`** ณ บรรทัดที่ 9-12 ตอนที่จะทำการรันสร้างโครงสร้าง):
     ```php
     define('DB_HOST', 'localhost'); // ที่อยู่ MySQL Host (ทั่วไปคือ localhost)
     define('DB_USER', 'root');      // ชื่อผู้ใช้งานฐานข้อมูลโรงเรียน
     define('DB_PASS', '');          // รหัสผ่านเข้าฐานข้อมูล
     define('DB_NAME', 'bannongwa_db'); // ชื่อฐานข้อมูลโรงเรียนที่ประสงค์ใช้งาน
     ```

3. **สำหรับการรันติดตั้งในครั้งแรก (First-run Setup)**:
   - อัปโหลดไฟล์ทั้งหมดขึ้นเว็บไซต์ผ่าน Git
   - พิมพ์ในช่อง URL เบราว์เซอร์ไปยังที่อยู่: `https://[โดเมนหลักของโรงเรียน]/db_migrate.php`
   - ระบบจะดำเนินการตรวจจัดตาราง พร้อมสตรีมข้อมูลสถิติ-ข้อมูลจำลองพร้อมทดสอบแสดงผลได้ทันทีโดยไม่ต้องนำเข้าไฟล์ `.sql` ใน PHPMyAdmin เลย!
